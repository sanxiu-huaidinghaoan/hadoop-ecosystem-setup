# 核心组件版本兼容性
# =============================================

组件			推荐版本		兼容范围		关键说明
Hadoop		3.3.6			3.1.0 - 3.4.x	必须使用 Hadoop 3.x
Hive			4.0.1			4.0.x			兼容 Hadoop 3.3.6
JDK			11			8, 11			推荐 JDK 11，不支持 JDK 17+
PostgreSQL	13.12		11.x - 15.x		避免使用 PostgreSQL 16+
Spark		3.3.3			3.0.x - 3.5.x	关键：匹配 Hive-Spark 版本
HBase		2.4.18		2.2.x - 2.5.x	需要对应 HBase Storage Handler
Hue			4.11.0		4.10.x - 4.12.x	需要适配 Hive 4.x 语法
Zookeeper	3.8.3			3.4.x - 3.8.x	元数据高可用需要
JDBC: 		42.6.0 
gitlab
Keepalived	防止gitlab的主节点宕机 自动切换从节点 主节点修复后自动传回

节点1: NameNode + ResourceManager + HMaster + GitLab + Kafka
节点2: SecondaryNameNode + NodeManager + RegionServer + Hive
节点3: NodeManager + RegionServer + Spark + ZooKeeper
节点4: NodeManager + RegionServer + Kafka + PostgreSQL
节点5: NodeManager + RegionServer + Kafka + Flume
节点6: 监控节点 (Prometheus + Grafana + ELK)

- zookeeper (选举服务)
- Storm / Flink (实时处理)

# =============================================
# 部署注意事项
# =============================================

1. 版本匹配: 确保 Hadoop 3.3.6 + Hive 4.0.1 + JDK 11 的核心组合
2. 网络配置: 确保各节点间网络通畅，防火墙规则正确
3. 存储规划: 根据数据量合理分配 HDD 和 SSD
4. 监控先行: 部署初期即建立完整的监控体系
5. 安全基线: 从第一期开始实施基础安全措施
